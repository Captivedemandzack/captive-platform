# Runbook: Image Production Workflow

Use this for sourcing and generating site imagery.

## 1. Define Image Style

Fill `agency/brief/image-style-guide.md`.

Lock:

- Lighting.
- Mood.
- Color grade.
- Subjects.
- Wardrobe.
- Composition.
- Compliance restrictions.

## 2. Build Image Inventory

List every required image before sourcing.

## 3. Source References

Use Lummi for visual references and source candidates.

## 4. Generate Or Adapt

Use Nano Banana or another image model only when reference/source images do not satisfy the role.

Keep prompts consistent across the site.

## 5. Optimize

Every production image should have:

- Correct dimensions.
- Descriptive alt text.
- Known source or generation note.
- Optimized file size.
