# Section Quality Gate

Use this before accepting any homepage or location-page section.

## Inputs

- Client brief and compliance notes.
- The relevant section packet.
- Latest live reference hunt summary.
- Latest screenshot index.
- Brand hack synthesis and design variables.

## Creative Director Check

A section is not ready if it can be described as only a layout. It needs a point of view: hierarchy, visual rhythm, trust cues, CTA behavior, responsive polish, and a reason it belongs to this client.

Ask these questions before moving on:

- Which reference screenshots shaped this section?
- What did we borrow: layout, density, CTA pattern, trust cue, image treatment, or interaction?
- What did we change so it becomes client-specific, not a copy?
- Are all editable fields still coming from JSON?
- Are there any broken images or placeholder image URLs?
- Does mobile look designed, not merely stacked?
- Does the section avoid the anti-positioning signals named in the client brief?
- Does it avoid unsupported medical claims?

## Mandatory Revisions

Revise before accepting if any of these are true:

- The section uses typography that conflicts with the approved brand direction.
- The section is mostly text on an empty background.
- The section uses `placehold.co`, broken external images, or unresolved image assets.
- The section ignores the reference screenshots.
- The section hardcodes editable copy into JSX.
- The section feels like a generic component library demo.
