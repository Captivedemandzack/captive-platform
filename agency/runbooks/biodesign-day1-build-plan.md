# BioDesign Day 1 Build Plan

This runbook adapts `BioDesign_Day1_Build_Plan.md` into the canonical Captive client-site workflow.

## Goal

Create enough visible progress to show momentum:

- Homepage direction.
- One location page direction, preferably Tampa.
- BioDesign-specific rules and project memory loaded.
- Brand tokens and image direction ready for a Next.js build.

## Sequence

1. Lock BioDesign brand direction.
2. Capture reference anchors and layout patterns.
3. Create image style guide and image inventory.
4. Write homepage and location page specs.
5. Build section by section.
6. Keep editable copy and images in JSON-compatible fields.

## Brand Anchors

- Marek Health: clinical authority and editorial dark tone.
- Hone Health: warm conversion structure and trust density.
- The Well NYC: luxury wellness restraint and spacing.

## Homepage Sections

1. Hero split.
2. Trust bar.
3. Services grid.
4. Why BioDesign.
5. How it works.
6. Locations grid.
7. Testimonials.
8. Final CTA.

## Image Direction

Use:

- Warm clinical lighting.
- Confident clothed professionals ages 35-55.
- Consultation settings.
- Modern clinical interiors.
- Eye-level perspective.
- Shallow depth of field.
- Slight desaturation.

Avoid:

- Shirtless.
- Gym equipment.
- Supplements.
- Bodybuilding.
- Blue LED labs.
- Cold stock medical imagery.

## Build Reminder

The original Day 1 plan includes useful prompts, but the build must preserve the Captive Studio architecture:

- Editable text belongs in JSON fields.
- Editable images belong in JSON image objects.
- Next.js components own layout, motion, and art direction.
- Every editable field must map to a stable field path.
