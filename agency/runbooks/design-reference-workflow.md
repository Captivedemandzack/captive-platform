# Runbook: Design Reference Workflow

Use this before designing major pages.

## 1. Collect References

Gather 5 to 8 sites:

- Direct competitors.
- Adjacent premium brands.
- High-converting category leaders.
- Sites with useful section patterns.

## 2. Analyze Each Site

Capture:

- URL.
- Useful sections.
- CTA hierarchy.
- Trust signals.
- Palette.
- Typography.
- Image style.
- Interaction style.
- What to avoid.

Save to `agency/refs/reference-sites.md`.

## 3. Synthesize Brand Hack

Convert the references into:

- Palette direction.
- Typography direction.
- Section rhythm.
- CTA system.
- Image direction.

Save to `agency/refs/brand-hacks.md`.

## 4. Build From Synthesis

Do not copy sections directly. Translate the useful pattern into a client-specific, custom-coded section.
