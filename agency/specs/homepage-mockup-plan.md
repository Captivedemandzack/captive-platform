## Build Order

Build one section at a time. Do not ask the agent to build the full page in one prompt.

## Captive Studio Boundary

Editable:

- Text.
- Images.
- Alt text.
- Metadata.
- Safe CTA labels and URLs.

Not editable:

- Layout.
- Section order.
- Animation.
- Colors.
- Typography.
- Component variants.
