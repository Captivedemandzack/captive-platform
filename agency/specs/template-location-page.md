# Location Page Template Spec

## Purpose

Create a local landing page for one physical market or clinic location.

## Suggested Sections

- Location hero.
- Address/contact block.
- Provider or team block.
- Services available.
- Reviews/testimonials.
- Map or directions.
- FAQ.
- CTA.

## Suggested Editable Fields

```txt
hero.headline
hero.subhead
hero.image
location.name
location.address
location.phone
location.hours
services[0].title
services[0].body
testimonials[0].quote
testimonials[0].author
faqs[0].question
faqs[0].answer
cta.headline
cta.buttonLabel
```

## SEO Requirements

- Unique title.
- Unique description.
- LocalBusiness or MedicalClinic JSON-LD where relevant.
- Breadcrumb JSON-LD.
- Unique OG image when possible.
