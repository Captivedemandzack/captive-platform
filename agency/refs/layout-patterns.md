# Layout Patterns

Use this file to collect section and page patterns worth adapting.

The goal is to extract principles, not copy layouts directly.

## Hero Patterns

- Choose-your-path split hero for Men's and Women's paths.
- Full-bleed, editorial, generous negative space.
- Men's side can use dark premium clinical tone.
- Women's side can use warm cream tone.

## Trust Patterns

- Compact trust bar directly after hero.
- Patient count, rating, physician-led care, and location count.
- Keep proof scannable and above early fold.

## Service Presentation Patterns

- 5-6 core service cards.
- One-line description per card.
- Link each card to a deeper service page.
- Keep descriptions scan-friendly, not exhaustive.

## Location Patterns

- 4-location grid for Tampa, Orlando, Melbourne, Lake Mary.
- Include address, hours, phone, and booking link.
- Location cards should feel local and action-oriented.

## CTA Patterns

- Consultation-first CTA.
- Risk reversal under major CTAs.
- Avoid product-purchase language.

## FAQ Patterns

- Questions should reduce anxiety and clarify process.
- FAQ content should support schema generation.

## Interaction Patterns

- Restrained premium motion.
- Subtle fade/reveal, no noisy effects.
- Custom interactions should support clarity, not decoration.
