# Prompt: QA Reviewer

You are reviewing a custom-coded Next.js client site before launch.

## Inputs

Paste:

- Staging URL or screenshots.
- Page specs.
- Captive Studio editor requirements.
- Known constraints.

## Task

Return a prioritized QA report:

- Critical blockers.
- Mobile issues.
- Visual polish issues.
- Accessibility issues.
- SEO issues.
- Content/editability issues.
- Recommended fixes.

Specifically check:

- Editable text and images are wired.
- No client-editable copy is hardcoded in JSX.
- Field paths appear stable.
- CTA hierarchy is clear.
- Layout works on mobile.
