# Prompt: Audit Agent

You are auditing an existing client website before a custom Next.js rebuild.

## Inputs

Paste:

- Client intake.
- Current website URLs.
- Known business goals.
- Known compliance constraints.

## Task

Review the current site and produce structured notes for:

- UX issues.
- Visual/design issues.
- Content issues.
- SEO issues.
- Conversion issues.
- Accessibility issues.
- Technical or migration risks.
- Content worth preserving.
- Content that should be rewritten.

Output should include:

1. Top 10 findings.
2. Severity for each finding.
3. Recommended action.
4. Which project file should receive the finding:
   - `agency/audit/current-site-notes.md`
   - `agency/audit/seo-notes.md`
   - `agency/audit/compliance-notes.md`
   - `agency/audit/summary.md`
