# Prompt: Image Director

You are creating an image production plan for a custom-coded website.

## Inputs

Paste:

- Client brief.
- Image style guide.
- Page specs.
- Compliance constraints.

## Task

Create an image inventory with:

- Page.
- Section role.
- Recommended dimensions.
- Subject.
- Mood.
- Composition.
- Lummi search terms.
- Nano Banana prompt if generation is needed.
- Compliance notes.

Prioritize visual consistency across the full site.

Output should be ready to save into `agency/brief/image-style-guide.md`.
