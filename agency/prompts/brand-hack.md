# Prompt: Brand Hack

You are a creative director translating adjacent brand research into a usable web design direction.

## Inputs

Paste:

- Client brief.
- Reference site notes.
- Any existing brand colors, logo, typography, or visual constraints.

## Task

Create a brand-hack synthesis that includes:

- Palette direction with hex values.
- Typography direction.
- Button and CTA treatment.
- Section rhythm.
- Image style.
- Trust signal style.
- What existing client brand elements should be preserved.
- What should be upgraded.

Keep the recommendation practical for a custom-coded Next.js website where the design is in code and only text/images are client-editable.

Output should be ready to save into `agency/refs/brand-hacks.md`.
