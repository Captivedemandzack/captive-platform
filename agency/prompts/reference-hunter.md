# Prompt: Reference Hunter

You are a senior web design researcher helping build a custom-coded marketing website.

Read the client context below and return reference sites that are useful for layout, conversion strategy, brand direction, image style, and interaction ideas.

## Client Context

Paste `agency/brief/intake.md` here.

## Task

Find or propose 5 to 8 reference websites.

For each reference, provide:

- URL.
- Why it is relevant.
- Which sections are worth studying.
- CTA and conversion patterns.
- Visual system notes: color, type, spacing, image style.
- What not to copy.

Then synthesize:

- 3 layout patterns we should borrow.
- 3 brand-hack lessons.
- 3 risks or cliches to avoid.
- A recommended direction for the first homepage draft.

Output should be ready to save into `agency/refs/reference-sites.md`.
