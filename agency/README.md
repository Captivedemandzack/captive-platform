# Agency Project Memory

This folder stores the durable memory for the client build.

Use it to turn a creative director's process into repeatable, agent-readable inputs.

```txt
brief/      Client inputs, positioning, constraints, and image direction.
audit/      Current-site findings, SEO notes, compliance notes, and migration risks.
refs/       Reference sites, layout patterns, and brand-hack notes.
specs/      Page and feature specs that agents can build against.
prompts/    Reusable manual-agent prompts.
runbooks/   Repeatable workflows and launch checklists.
```

The rule: if a decision matters, write it here before expecting an agent to remember it.
